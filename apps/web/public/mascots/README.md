# Kitchen assets

- `steve-poses.webp`: original generated CoSoup artwork, four transparent cel poses.
- `steve.webp`: original generated CoSoup artwork, separate pan-tossing pose.
- `bowl.webp`: original generated CoSoup artwork, the bowl used in the Canvas kitchen.
- `bowl-idle.webp`: 48-frame, two-second transparent loop from the original procedural Blender bowl scene.
- `bowl-poster.webp`: static Blender bowl for paused/reduced motion.

These original assets are distributed under the repository MIT license. The optimized files total about 580 KB and are served locally. No third-party meme images are embedded; “Let him cook” is used as playful text. Decorative ticker symbols do not represent current holdings, recommendations, prices or progress.

See `tools/mascots/README.md` for editable source and reproduction commands. Animation behavior lives in the web kitchen components; runtime installations need neither Blender nor FFmpeg.
