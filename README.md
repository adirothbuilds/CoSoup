# Stock Scanner

Personal-use research tooling for end-of-day US equity screening across sectors and company sizes.

## Status

Initial repository setup. The Massive data integration and live-data validation are in progress.

## Scope

- Reproducible price, volume, trend, relative-strength, and liquidity screening.
- Explicit coverage, freshness, corporate-action, and missing-data checks.
- Research reports only. No brokerage connection or automated trading.

## Credentials

Keep provider credentials in the execution environment's secure secret configuration. Never commit keys, credential files, raw headers, or private account details.

This software does not guarantee returns and is not a substitute for independent investment research.
